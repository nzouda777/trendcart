# Milestone 1: foundations and connections

Status: done, QA passed ([qa/milestone-1.md](../qa/milestone-1.md)). Demo: create a workspace,
connect a store, an ad account and a profile, paste a TikTok link, see the AI analysis and
confirm the product at Gate 1. Runs fully in mock mode on a local PGlite database
([setup.md](../setup.md)).

## Delivered

- **Foundation**: Better Auth (email + password, required email verification, optional TOTP,
  organization plugin = workspace) with roles `owner`, `media_buyer`, `creative`, `viewer`
  (`lib/auth/permissions.ts`). Drizzle schema and migrations for every Phase 2 table, all
  business tables with `workspace_id` and composite tenant FKs. Scoped data access
  (`lib/tenant/scoped-db.ts`), AES-256-GCM keyring with AAD (`lib/crypto`), audit log, seed with
  two demo workspaces.
- **Shopify**: OAuth install (public unlisted app or per-store custom app), HMAC verification,
  expiring offline tokens with refresh, webhooks (`app/uninstalled` and compliance topics),
  metafield definitions (`custom.highlights`, `custom.faq`, `custom.guarantee`), theme template
  discovery in the adapter.
- **TikTok**: Marketing API advertiser OAuth and advertiser listing; Login Kit OAuth for
  profiles with publish scopes; hourly profile-token refresh cron; SELF_ONLY enforcement until
  the posting audit. Campaign, upload, stats and posting methods are stubs that throw
  "not implemented" (M3).
- **Sourcing and AI**: ScrapeCreators TikTok data adapter (link resolve, keyword search), DNS-level
  SSRF guard, per-brand proxy dispatch, Gemini product analyzer (video via Files API, or product
  page text), AI metering and monthly cap.
- **Workflow and services**: product state machine, job runner with retries and per-workspace
  concurrency, inline pipeline (analyze step), services for brands, proxy, connections, products,
  GATE 1, team and usage, import rate limit.
- **App screens** under `/app/*`: overview, onboarding, brands, connections (health colours,
  proxy, template suffix), import, products list and detail (gate tracker, analysis, retry,
  GATE 1), team, usage, account security.
- **QA**: isolation suite (two tenants), M1 demo-flow test, security suite; follow-up fixes for
  open redirects, SSRF, proxy schemes, rate limits, security headers, mock-in-production guard,
  `server-only` coverage.
- **Local DB**: `DATABASE_URL=pglite:./.data/dev` (dev only), opened by `instrumentation.ts`.

## Decisions

- **Vercel Workflow** (Workflow DevKit) chosen as the durable engine for M2. M1 runs the analyze
  step inline through the same `ProductPipeline` interface (`lib/workflows/pipeline.ts`), so
  services do not change when the engine lands.
- **ScrapeCreators** as the TikTok data provider (`TIKTOK_DATA_PROVIDER=scrapecreators`).
  Media URLs are resolved just in time and never stored.
- **Gemini** (`gemini-3.8-flash` by default) for product analysis.
- **PGlite** as the local development fallback, refused in production.
- **`proxy.ts`** instead of `middleware.ts` (Next 16 naming). It only checks for a session
  cookie on `/app/*`; real checks happen in every page and service.
- App routes live under **`/app/*`** (`app/(app)/app/...`), leaving `/` to the landing page.
- Non-embedded Shopify app; security headers forbid framing (`frame-ancestors 'none'`).

## Known limitations

- Live email goes through Resend (verification, invitations); password reset is not built yet.
- Template suffix is typed by hand; there is no template picker yet.
- No screen to enter a TikTok Marketing API sandbox token.
- After Gate 1, products wait in "Finding suppliers" (sourcing is M2).
- Encryption key rotation has no bulk re-encryption job.
- `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `PERPLEXITY_API_KEY`, `SERPAPI_KEY`,
  `FIRECRAWL_API_KEY` and `SENTRY_DSN` are documented but unused.

## Open questions carried to M2

1. **Schema**: dedicated Shopify refresh-token columns (`refresh_token_enc`,
   `token_expires_at`) instead of the encrypted JSON token bundle in `access_token_enc`.
2. **Schema**: connection statuses `expiring` / `revoked` (today: `active`, `pending`,
   `needs_reauth`, `disconnected`).
3. **Schema**: `refresh_expires_at` on `tiktok_profile_connection` (TikTok refresh tokens last
   365 days).
4. **Password reset** flow (Resend is wired; pages and Better Auth `sendResetPassword` are not).
5. **Per-workspace AI cap override** (today `AI_MONTHLY_CAP_USD` is global).
6. **Products list thumbnail preference**: TikTok thumbnails are signed and expire; prefer the
   analysis reference image, then the Shopify media URL (M2) or the chosen supplier image.
7. **`listShopifyTemplates` service** so the UI can offer the theme's product templates instead
   of a free-text suffix.
8. **Marketing API sandbox token entry** (the sandbox has no OAuth flow).
9. **Workflow engine wiring**: add `workflow@5.2.3` and wrap `next.config.ts` with
   `withWorkflow` (orchestrator-owned file).
10. **`frame-ancestors 'none'` vs an embedded Shopify admin**: if the client wants Trendcart
    inside the Shopify admin, the CSP must allow `https://*.myshopify.com` and
    `https://admin.shopify.com` for that surface.

The Shopify template kit (`product.trendcart` template bound to the `custom.*` metafields) ships
with M2 draft product creation.
