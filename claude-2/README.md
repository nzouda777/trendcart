# Trendcart — Phase 2 kit for Claude Code

## Installation

1. Copy the `.claude/agents/` folder to the root of your Trendcart repo (the one with the landing page).
2. Copy `CLAUDE-phase2.md` to the root of the repo.
3. Open Claude Code at the root of the repo and paste the content of `PHASE2_PROMPT.md`.

## Contents

| File | Role |
| --- | --- |
| `PHASE2_PROMPT.md` | The prompt to paste into Claude Code (orchestrator / tech lead) |
| `CLAUDE-phase2.md` | Project context Claude Code appends to `CLAUDE.md` |
| `.claude/agents/foundation-engineer.md` | Auth, workspaces, roles, database, encryption, app shell |
| `.claude/agents/shopify-integration.md` | Shopify OAuth, webhooks, templates, products, media |
| `.claude/agents/tiktok-integration.md` | TikTok Ads and TikTok posting |
| `.claude/agents/sourcing-ai.md` | TikTok data, AI analysis, suppliers, margin, compliance, copywriting |
| `.claude/agents/workflow-engineer.md` | Pipeline, approval gates, state machine, services, video lifecycle |
| `.claude/agents/app-ui.md` | Product app screens |
| `.claude/agents/qa-reviewer.md` | Tests, tenant isolation, security, milestone reports |
| `.claude/agents/docs-writer.md` | Setup, user guide, Shopify template kit, runbook |

The `.claude` folder is hidden on macOS and Linux. Show hidden files to see it (Cmd + Shift + . in the macOS Finder).
